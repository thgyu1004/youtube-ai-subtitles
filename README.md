# YouTube AI 한국어 자막 (Tampermonkey)

만든 사람: **J.S.Lee**

## 자동 업데이트 설치

[스크립트 설치 / 업데이트](https://raw.githubusercontent.com/thgyu1004/youtube-ai-subtitles/main/youtube-ai-subtitles.user.js)

위 주소를 크롬에서 열어 Tampermonkey 설치/업데이트 화면을 진행하세요. 감지되지 않으면 파일 전체를 기존 스크립트 편집기에 붙여 넣고 저장합니다. 동일한 이름/namespace의 기존 스크립트를 교체하면 저장된 키와 설정을 유지합니다.

버전 0.1.3부터 GitHub의 고정 주소로 업데이트를 확인합니다. Tampermonkey의 해당 스크립트 설정에서 업데이트 확인을 활성화하세요. 갱신은 설정된 확인 주기를 따르며, 즉시 확인하려면 대시보드에서 업데이트 확인을 실행합니다.

개발자는 수정 후 `@version`을 올리고 `.user.js`와 `.meta.js`의 버전 및 헤더를 일치시켜 GitHub `main`에 게시해야 합니다. 로컬 파일 수정만으로 온라인 버전이 갱신되지는 않습니다.

## 설치

1. 크롬에 공식 Tampermonkey 확장 프로그램을 설치합니다: https://www.tampermonkey.net/
2. 확장 프로그램 메뉴 → 대시보드 → 새 스크립트(+)를 엽니다.
3. 기본 코드를 모두 지우고 `youtube-ai-subtitles.user.js` 전체 내용을 붙여 넣은 뒤 Ctrl+S로 저장합니다.
4. 확장 프로그램이 사용자 스크립트 실행 허용을 요구하면 크롬의 확장 프로그램 상세 설정에서 허용합니다. 설치된 크롬/Tampermonkey 버전에 따라 개발자 모드가 필요할 수 있습니다.
5. 유튜브 영상 페이지를 새로고침합니다.
6. 오른쪽 위 ‘AI 한국어 자막’ → 설정에서 Gemini API 키를 입력합니다. 키 발급: https://aistudio.google.com/apikey
7. ‘번역 시작 / 이어서’를 누릅니다. 자막 언어를 바꾸려면 목록에서 선택한 후 다시 시작합니다.

모델 404 오류가 발생하면 설정 → **사용 가능한 모델 불러오기** → 모델 선택 → 저장을 진행하세요. API 키로 Google의 모델 목록을 조회하며, 번역이나 자동 모델 전환은 하지 않습니다. 목록에 나오는 모델의 무료 할당량과 JSON 응답 지원은 별도 확인이 필요합니다.

## 비용과 개인정보

- 이 스크립트 자체는 무료입니다. Gemini 무료 할당량과 이용 가능 모델은 Google 정책에 따릅니다. 결제가 연결된 API 프로젝트는 사용량에 따라 비용이 발생할 수 있습니다.
- 무료로만 사용하려면 결제가 활성화되지 않은 프로젝트의 무료 지원 모델을 사용하고 AI Studio에서 할당량을 확인하세요. 스크립트는 계정의 무료/유료 여부를 판별하지 못합니다.
- 기본 모델 ID는 `gemini-2.5-flash`입니다. 해당 모델이 계정에서 지원되지 않거나 종료되면 설정에서 현재 사용 가능한 텍스트 모델 ID로 바꿉니다.
- 원어 자막 및 앞부분 문맥이 Google로 전송됩니다. 무료 서비스의 데이터 이용 정책을 확인하세요: https://ai.google.dev/gemini-api/docs/pricing
- API 키는 Tampermonkey의 스크립트 전용 저장소에 저장됩니다. 키가 들어간 스크립트나 설정을 다른 사람에게 공유하지 마세요. 페이지 DOM이나 번역 캐시에 키를 기록하지 않습니다.

## 동작

- 원어/자동자막이 있는 일반 `/watch?v=...` 영상 지원. Shorts, 실시간 방송, 자막 없는 영상의 음성 인식은 지원하지 않습니다.
- 현재 재생 위치부터 최대 40개 자막씩 번역하며, 이후 남은 앞부분도 처리합니다. 번역할 구간으로 이동하면 다음 요청에서 그 위치를 우선합니다.
- 원어 자동자막 오류와 문장이 잘린 타이밍은 완전히 복구할 수 없습니다. 타임코드를 유지하면서 주변 문맥으로 번역합니다.
- 중지 버튼은 진행 중 요청을 취소하지만 이미 서버가 처리한 요청은 사용량에 반영될 수 있습니다. 완료된 번역은 계속 표시되고, 다시 시작하면 저장된 결과를 재사용합니다.
- 영상/원어/모델/자막 내용별로 번역을 저장합니다. 설정의 캐시 삭제로 모든 번역 기록을 지울 수 있습니다.
- 전체화면에서도 영상 플레이어 안에 자막을 표시합니다. 유튜브 기본 자막이 겹치면 CC를 끄세요.

## 문제 해결과 검증 범위

- 키 오류: 설정의 API 키와 Google 프로젝트 권한을 확인합니다.
- 429: 무료 요청 속도 또는 하루 할당량 제한일 수 있습니다. 나중에 이어서 시작합니다. 자동 유료 전환이나 무한 재시도는 없습니다.
- 자막을 가져오지 못함: 유튜브 기본 CC를 켠 뒤 새로고침하고 재시도합니다. 그래도 안 되면 해당 영상의 자막 접근 제한 또는 유튜브 내부 구조 변경일 수 있습니다.
- 실제 유튜브 자막 접근은 비공개 내부 구조에 의존하므로 모든 영상에서 보장되지 않습니다.
- 구문 검사와 모의 데이터로 자막 파싱·번역 응답 검증·사용량 오류·재생 시간 경계를 확인했습니다. 실제 계정/API 키를 사용하는 유튜브 통합 검증은 사용자의 설치 후 필요합니다.
